# Разработка NOEZEMA

## Требования

- Python 3.11 или 3.12
- доступ к Python Package Index либо совместимому локальному mirror при первом bootstrap

Для создания изолированного окружения и установки dev-зависимостей выполните:

```shell
python scripts/bootstrap.py
```

Скрипт создаёт `.venv` в корне проекта. Активировать окружение необязательно: проверки можно
запустить его интерпретатором напрямую.

Linux/macOS:

```shell
.venv/bin/python scripts/check.py
```

Windows PowerShell:

```powershell
.venv\Scripts\python.exe scripts\check.py
```

`check.py` является единой точкой входа для локальных проверок и CI. Он последовательно
запускает Ruff, проверку форматирования, компиляцию Python-модулей и pytest.

Перед коммитом полный `check.py` должен завершаться успешно. Новые зависимости добавляются в
`pyproject.toml`; системные и секретные настройки в репозиторий не коммитятся.
